Methodology

Data sources and methods

Final regular-season league tables for five women's and five men's top-flight leagues: 73 league-seasons and 1,229 team records. Every row in both datasets includes a source and a source_url column.

Downloads

team_seasons.csv 1,229 rows · 212 KB league_seasons.csv 73 rows · 12 KB

team_seasons.csv has one row per team per season: games played, wins, draws, losses, goals, points, win/draw/loss percentages and goal difference per game.

league_seasons.csv has one row per league-season: number of teams, average games, standard deviation of win percentage and the Noll–Scully ratio, with and without FC Barcelona for Liga F.

Sources

  • RSSSF (Rec.Sport.Soccer Statistics Foundation): volunteer-run archive of league tables. One page per league-season; the link is in each row's source_url. rsssf.org
  • English Women's Football Database: Rob Clapp (May 2024), featured as a TidyTuesday dataset (2024-07-16). TidyTuesday on GitHub
  • openfootball/football.json: open, public-domain match results. Tables were built from the match results. openfootball on GitHub
  • futbol24: commercial results site, used only for the three 2024–25 tables that RSSSF does not yet have. futbol24.com

How the tables were collected

  • Downloaded directly in code: openfootball and the English Women's Football Database.
  • Transcribed from the source web pages: RSSSF and futbol24 tables were read from each web page and entered into the dataset.

For openfootball, each team's games played, wins, draws, losses and goals were added up from the match results. Points are calculated as 3W + D, so points deductions are not reflected; wins, draws, losses and goals are unaffected.

Checks applied to every table

  1. W + D + L = games played, for every team.
  2. League totals: wins = losses, goals for = goals against, and total draws is an even number.
  3. Points = 3W + D, unless a points deduction is documented.

All 73 tables pass checks 1 and 2. Six rows fail check 3 because of real points deductions, which do not affect wins, draws, losses or goals.

Corrections to the source

Two RSSSF typos were corrected so that points = 3W + D:

  • NWSL 2025, Kansas City Current: 55 → 65 points (21 wins, 2 draws, 3 losses).
  • NWSL 2023, Portland Thorns: 36 → 35 points (10 wins, 5 draws, 7 losses).

Calculated fields

FieldDefinition
win_pct, draw_pct, loss_pctWins, draws or losses ÷ games played.
gd_per_game(Goals for − goals against) ÷ games played.
sd_win_pctPopulation standard deviation of win percentage across all teams in the league-season.
noll_scully Actual standard deviation of win percentage ÷ the standard deviation expected if every team were equally good. Expected SD = √(p(1−p) × mean(1/Gi)), where p is the league's average win percentage and Gi is each team's games played (this handles uneven schedules). 1.0 means as even as chance; higher means less balanced.
*_no_barcaThe same calculations for Liga F with FC Barcelona's row removed.

Known limitations

  • COVID-shortened seasons are included: 2019–20 WSL, Première Ligue, Liga F and Ligue 1, and MLS 2020. These seasons have fewer games, or uneven numbers of games between teams.
  • MLS combines both conferences into one table, even though MLS plays an unbalanced schedule.
