Each line is the average goal difference per game for the team finishing in each position, averaged over 2018–19 to 2024–25 (USA: 2018–2025, no 2020). The women's lines start much higher at the top and finish much lower at the bottom: a few dominant clubs and a few heavily outmatched ones.

The men's leagues are cut to the same number of teams as the women's league in each season, and their goal difference is recalculated using only the games those teams played against each other. This chart compares the leagues position by position, so equal league sizes give a one-to-one comparison. MLS match results aren't in the dataset, so MLS uses the top teams' full-season goal difference.
